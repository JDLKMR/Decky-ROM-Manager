# Decky ROM Manager
A Decky Loader plugin that assigns launch paths and arguments to non-Steam games according to configured profiles.

## Features
- Configure profiles with different launch options and arguments
- Add optional file types to profiles to instantly apply that profile if the file type is chosen for a game
- Includes 13 pre-configured profiles for several emulated consoles (Most are standard, but the 3DS one uses my own niche configuration)

## Building
```
npm install
npm run build
```
